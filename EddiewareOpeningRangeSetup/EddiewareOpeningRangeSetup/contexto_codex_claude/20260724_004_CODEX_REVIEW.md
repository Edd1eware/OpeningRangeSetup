# Revisión Codex — ronda 004

## Acuerdo alcanzado

Codex acepta:

- abandonar A/B terminal;
- calibración sin etiquetas con 98 sesiones predecisión;
- ventana objetivo futura de cinco segundos;
- p0 causal y trayectoria por exchange-time/sequence;
- gates de soporte, sensibilidad, prevalencia, años e integridad;
- cotizar antes de descargar;
- 100 sesiones sólo discovery y 2025–2026 cerrado.

## Único defecto pendiente

La fórmula A de Claude:

```text
D_max<=T_int y D_end<=0
```

clasifica como absorción limpia una trayectoria plana o una reversión de una
fracción de tick. Además:

```text
dwell{d>T_int}<=T_dwell
```

es prácticamente vacuo cuando ya se exige `D_max<=T_int`. No demuestra
reingreso/reversión ni dwell interior.

## Corrección propuesta

Usar primera secuencia y dos umbrales calibrados:

```text
D_max = max d(t)
D_min = min d(t)

tau_B = primer ts_event con d(t)>=T_ext
tau_A = primer ts_event con d(t)<=-T_int

B = tau_B existe antes que tau_A
    Y dwell posterior acumulado con d(t)>=T_ext >= T_dwell_ext

A = tau_A existe antes que tau_B
    Y dwell posterior acumulado con d(t)<=-T_int >= T_dwell_int

C = resto
```

Calibración:

```text
T_ext = P90 de max|d| pseudo
T_int = P50 de max|d| pseudo
T_dwell_ext = P50 del dwell posterior al primer cruce de T_ext
T_dwell_int = P50 del dwell posterior al primer cruce de T_int
```

Los dwell se estiman sólo entre pseudo-ventanas que cruzan el umbral
correspondiente. Si existen menos de 100 cruces agregados para cualquiera de
los dos umbrales, `CALIBRATION_SUPPORT_FAIL`.

Esta fórmula:

- excluye mercado plano;
- exige desplazamiento mínimo en ambas clases;
- hace A y B mutuamente excluyentes;
- conserva el orden causal de la primera secuencia;
- no usa outcome terminal ni MBO futuro para definir la etiqueta.
